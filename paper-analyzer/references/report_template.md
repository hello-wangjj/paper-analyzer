# 报告模板

> 这是 paper-analyzer 技能的固定输出模板。每次分析论文时，使用此模板生成报告骨架，然后基于论文原文补全内容。
>
> 写作前先判定论文的主类型与必要的次类型，只走适合该论文的证据路径。固定章节用于固定阅读问题和证据责任，不代表每篇论文都必须有实验、公式、图片、代码或外部文献。
>
> 默认输出语言为中文；论文标题、作者名、公式符号、数据集/方法正式名称保留原文。
> 若某些信息无法确认，明确写出"论文未提及 / 原文未明确说明 / 当前未检索到可靠文献"。
